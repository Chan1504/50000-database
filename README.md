# Voter Data Android Application

An Android application developed using **Android Studio** for working with and displaying voter-related data. The application includes a voter dataset bundled directly inside the APK for local use.

## 📱 Application

This application provides an Android-based interface for working with voter data and performing voter-related data operations.

## ✨ Features

* Voter data management
* Voter data search and viewing
* Local voter dataset
* CSV dataset integration
* Android-based user interface
* Offline access to bundled voter data
* Supports a large voter dataset

## 📊 Dataset

The application includes a voter dataset in CSV format:

```text
assets/voters.csv
```

The dataset is packaged inside the Android application and can be accessed by the application during runtime.

## 🛠️ Technologies Used

* **Android Studio**
* **Kotlin**
* **Android SDK**
* **CSV Dataset**
* **Git & GitHub**

## 📦 APK

The compiled Android application is provided in the repository.

```text
APK/
└── app-debug.apk
```

### Installation

1. Download `app-debug.apk`.
2. Transfer the APK to an Android device.
3. Open the APK file.
4. If required, allow installation from unknown sources.
5. Install the application.
6. Open the application and use the voter-data features.
